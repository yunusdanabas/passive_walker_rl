# Tools Directory

This directory contains analysis and utility tools for the passive walker RL project.

## Structure

- `evaluation/` - Model evaluation scripts and comprehensive testing tools
- `analysis/` - Data analysis, model diagnostics, and optimization tools
- `visualization/` - Plotting and visualization utilities

## Usage

These tools are designed to work with the new directory structure and will automatically save outputs to the appropriate `experiments/outputs/` subdirectories.
