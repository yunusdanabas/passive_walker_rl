# Data Directory

This directory contains training data and model outputs that are **not tracked by git**.

## Directory Structure

```
data/
├── fsm_runs/           # FSM demonstration data
│   ├── episode_*.npz   # Episode data files
│   └── meta.json       # Collection metadata
├── fsm_runs_long/      # Extended FSM data
├── fsm_runs_dr/        # Domain randomized FSM data
└── bc/                 # Behavior cloning data
    ├── raw/            # Raw training data
    └── test/           # Test/validation data
```

## File Types

- **`.npz`**: NumPy compressed episode data (observations, actions, rewards)
- **`.json`**: Metadata files (collection parameters, normalization stats)
- **`.pt`**: PyTorch model checkpoints
- **`.eqx`**: JAX/Equinox model checkpoints

## Usage

Data files are generated by:
- `python -m passive_walker.fsm.collect` - Creates FSM demonstration data
- `python -m passive_walker.bc.train` - Creates model checkpoints in `results/`

## Note

All data files are excluded from git via `.gitignore` to keep the repository lightweight.
